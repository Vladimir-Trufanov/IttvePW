## [Как в скетче ардуино узнать ...](#)

### [Какая плата подключена](#)

> ***В скетче Arduino нельзя «узнать» подключённую плату в runtime (во время работы прошивки) — плата уже определена на этапе компиляции. Но можно определить, для какой платы компилируется скетч, с помощью макросов препроцессора.***

Основные макросы для определения платы

```
ARDUINO_ARCH_AVR     — для классических плат на ATmega (Uno, Nano, Mega и т. д.).
ARDUINO_ARCH_SAMD    — для плат типа Arduino Zero, MKR, Due.
ARDUINO_ARCH_ESP32   — для соответствующих семейств, 
ARDUINO_ARCH_ESP8266 — для соответствующих семейств.
```

Пример:

```
#if defined(ARDUINO_ARCH_AVR)
  // код для Uno/Nano/Mega
#elif defined(ARDUINO_ARCH_SAMD)
  // код для Zero/MKR
#elif defined(ARDUINO_ARCH_ESP32)
  // код для ESP32
#endif
```

Для отдельных плат в Arduino Core часто определены свои макросы:

```
#define ARDUINO_AVR_UNO      — Arduino Uno;
#define ARDUINO_AVR_NANO     — Arduino Nano;
#define ARDUINO_AVR_MEGA2560 — Arduino Mega 2560;
#define ARDUINO_SAMD_ZERO    — Arduino Zero;
#define ARDUINO_ESP32_DEV    — для ESP32.
```


Пример проверки конкретной платы:

```
#if defined(ARDUINO_AVR_UNO)
  Serial.println("Плата: Arduino Uno");
#elif defined(ARDUINO_AVR_NANO)
  Serial.println("Плата: Arduino Nano");
#else
  Serial.println("Другая плата");
#endif
```

Важные нюансы

Макросы работают на этапе компиляции, а не в рантайме. То есть код под конкретную плату просто не попадёт в прошивку, если условие не выполнится.

Набор макросов зависит от ядра (Arduino AVR, SAMD, ESP32 и т. п.) и его версии. Например, у сторонних ядер могут быть свои определения.

Не все платы имеют уникальные макросы. Иногда проще ориентироваться на семейство (AVR, SAMD и т. д.) или на характеристики микроконтроллера.
Альтернатива: определять по характеристикам МК.

Если нужно не «название платы», а её возможности, часто проверяют микроконтроллер:

```
__AVR_ATmega328P__ — часто для Nano/Uno;
__AVR_ATmega2560__ — для Mega;
__arm__ или __xtensa__ — для ARM/Xtensa (Zero, ESP и т. п.).
```

Пример:

```
#if defined(__AVR_ATmega328P__)
  // ATmega328P: Uno/Nano
#elif defined(__AVR_ATmega2560__)
  // ATmega2560: Mega
#endif
```

Практический совет

Если ваша цель — адаптировать код под разные платы (например, выбрать пины или тайминги), лучше опираться на семейство/микроконтроллер, а не на «имя платы»: это делает код переносимее.

### [Какая плата подключена для ESP32]

> ***В Arduino IDE нет стандартного макроса, который прямо сообщал бы, какая именно плата подключена в данный момент. Но задачу решить можно конфигурационным файлом вручную.***

```
/** Arduino - ESP32 ******************************************* Howknow.ino ***
 * 
 * "Как в скетче ардуино узнать ..."
 * 
 * v1.0.0, 31.07.2026                                 Автор:      Труфанов В.Е.
 * Copyright © 2025 tve                               Дата создания: 31.07.2026
**/

#include <Arduino.h>
#include "config.h"  

void setup() 
{
  Serial.begin(115200);
  delay(5000);
  Serial.println("Подключена плата: " + String(BOARD_NAME));
}

void loop() 
{
  // put your main code here, to run repeatedly:
}

// ************************************************************ Howknow.ino ***
```

```
/** Arduino - ESP32 ********************************************** config.h ***
 * 
 * Cконфигурировать Howknow.ino
 * 
 * v1.0.0, 31.07.2026                                 Автор:      Труфанов В.Е.
 * Copyright © 2025 tve                               Дата создания: 31.07.2026
**/

#pragma once 

#define BOARD_NAME  "AI Thinker ESP32-CAM"

// *************************************************************** config.h ***

```

Перед тем как писать код, который зависит от типа платы, проверьте настройки в Arduino IDE: в меню «Инструменты» → «Плата» выберите ту модель, которую вы фактически используете. Часто этого достаточно, чтобы препроцессор корректно определил нужные символы, и дополнительные проверки в коде не потребовались.
